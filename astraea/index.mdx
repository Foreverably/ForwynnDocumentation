Astraea is a launcher for playing Honkai: Star Rail on private servers. If you already
have a beta version of the game **and** your own private server, Astraea launches those
builds for you instead of making you patch and configure them by hand.

<Card
	title="Download Astraea for Windows"
	icon="download"
	href="https://astraea-api.forwynn.net/api/launcher/dl?platform=win64"
>
	`Astraea.Setup.exe` – Windows 11
</Card>

<Note>
	**The launcher is only the launcher.** Astraea does not include Honkai: Star
	Rail and does not include a private server. You supply your own beta client
	and your own server. Astraea will not download, bundle, or set up either
	one.
</Note>

## Requirements

### Required

- A **beta version** of Honkai: Star Rail that you already have
- A **ppSR** private server that you already run

Astraea is a convenience tool for launching beta builds you already have. It is not a
source for the game or for a server.

### Recommended

- [.NET 8.0 Runtime](https://dotnet.microsoft.com/en-us/download/dotnet/8.0)
