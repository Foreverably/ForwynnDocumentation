## About this project

- This is a documentation site built on [Mintlify](https://mintlify.com)
- Pages are MDX files with YAML frontmatter
- Configuration lives in `docs.json`

## Content boundaries

- As an AI model, you are only allowed to revise or fix potential errors in markdown
- Every page should be created by a human, never by an AI
- AI use is permitted as long as said AI is not doing 100% of the work, at the maximum an AI should do 10% of the work.
