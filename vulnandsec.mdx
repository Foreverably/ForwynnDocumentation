We take the security of our services seriously. If you believe you have found a security vulnerability in any product / service that was made by Forwynn, please report it as described below.

## Reporting Security Issues

<Danger>
	Please do not report security vulnerabilities through public GitHub issues,
	public Discord channels, threads or anywhere else!
</Danger>

If you discover a security issue, please report it privately through our official Discord Support Server:

1. Join our support server.
2. Navigate to the feedback channel.
3. Open a **Vulnerability Reporting** ticket.

### What to Include in Your Report

To help us triage and fix the issue quickly, please include:

- **The affected project:** Explicitly state what project this is for.
- **Description:** A detailed explanation of the vulnerability and its potential impact.
- **Steps to Reproduce:** Clear, step-by-step instructions or a minimal Proof of Concept (PoC) script.
