Kycha is an upcoming alternative to most gacha collection Discord bots. Its main goal
is the collection and management experience those bots already handle well, built
around a set of unique features that existing bots don't offer.

## Get involved

There's nothing to test yet. If you're interested in the project as it comes
together:

<Steps>
  <Step title="Join the support server">
    [Forwynn's Refuge](https://discord.forwynn.net) is where Kycha development is
    discussed. Announcements and progress updates land there first.
  </Step>

  <Step title="Watch for testing calls">
    When testing opens, interested members will be able to join from the server before
    anything is publicly released.
  </Step>
</Steps>

<Warning>
	Kycha is an early idea and wasn't announced. Features, scope, and timeline
	are all subject to change.
</Warning>
